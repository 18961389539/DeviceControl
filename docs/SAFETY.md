# 安全与生产部署限制

**V0.2 仅能用于仿真和软件架构验证，禁止直接控制真实机械设备。**

必须处理的主要风险包括：

1. 风险评估与安全功能设计（如适用 ISO 12100、ISO 13849-1、IEC 62061）。
2. 急停、安全门、光幕、伺服 STO、气路卸压等必须根据风险评估通过独立或安全认证系统完成，不能依靠普通 PC / REST API / IO 输出。
3. 模式切换、人员进入、手动点动、抱闸控制、意外启动防护需符合实际设备的安全设计。
4. 对可失控气缸应根据阀型和气路确定通电、掉电和故障的安全状态；本示例双线圈互斥仅演示软件逻辑。
5. 对运动轴必须处理软硬限位、回零可靠性、编码器丢失、跟随误差、失电保持及减速停止。
6. 网络/API 层上线前应加入身份认证、权限、审计、CSRF 防护、隔离网络和部署白名单。本演示只监听 127.0.0.1，不具有生产级权限体系。
7. 当前 UI 自带的 `GuardClosed` 开关以及软件检查都**不是安全联锁**，演示模式里可以在运行中切换，目的是测试普通逻辑异常检测。
8. 停止请求是**普通软件取消请求**，并非急停或安全停止，不能保证立刻去能或实现规范的停止类别。
9. 故障恢复不能盲目按照本示例回零；真实设备需要考虑夹具状态、在途工件、轴位置、人员许可及回原点的运动风险。
10. 无法通过单纯仿真来认证设备功能安全、实时性或适配实际机械运动。
