# V0.5 纯软件开发计划 — 流程 Runtime 与资源调度

1. 可追踪执行标识：RunId、StepId、Attempt、CancelReason、运行参数快照；统一命令操作状态。
2. 并行分支、条件、循环、Join 节点，以及最大循环迭代和超时阈值。
3. 设备动作资源锁（轴 / 气缸 / 视觉任务），锁顺序与无死锁策略；静态检测潜在冲突。
4. 每一步可配置失败策略（Abort、Retry 幂等节点、WaitForOperator），加入带原因的取消和终止。
5. 流程定义版本、静态校验和仿真单元测试，不急于引入拖拽编辑器。
6. 将操作审计、周期记录、版本记录迁移到支持事务的 SQLite，补充并发场景及掉电异常的回放测试。

项目范围：只推进软件 Runtime、前端编辑与仿真测试，不开展实体设备适配。
